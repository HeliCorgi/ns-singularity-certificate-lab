## 1. 記法: 二進シェル分解

`Δ_j` を二進シェル射影(`|k| ~ λ_j = 2^j`)、`u_j = Δ_j u`、

```text
E_j(t) = ‖u_j(t)‖²_{L²},    E(t) = Σ_j E_j(t) = ‖u(t)‖²_{L²}.
```

外力あり Navier–Stokes のシェル別エネルギー収支は**恒等式**である:

```text
d/dt (½E_j) = −ν‖∇u_j‖² + Π_j + ⟨u_j, f_j⟩,        (1.1)
Π_j := −⟨u_j, Δ_j((u·∇)u)⟩,    Σ_j Π_j = 0.        (1.2)
```

(1.2) の総和ゼロは非線形項のエネルギー中立性
([track_f_finite_mode_nogo.md](track_f_finite_mode_nogo.md) Lemma 1)そのもので、
Lean では `NSSingularity.advectionForm_eq_zero`(F-12)が Fourier 表現で
機械検証している。

## 2. 出発点となる 2 つの既証明条件

有限次元性を一切使わない [track_f_finite_mode_nogo.md](track_f_finite_mode_nogo.md) §5 の
(N-1)(N-2) をそのまま使う。`f ∈ L¹((0,T);L²)`、`M = ∫₀ᵀ‖f‖` として

```text
(N-1)  sup_{t<T} E(t) ≤ (‖u(0)‖ + M)²  < ∞
(N-2)  ν ∫₀ᵀ Σ_j λ_j² E_j(t) dt < ∞
```

**(N-1)(N-2) は滑らかな外力の下で自動的に成り立つ。** したがってこの 2 つは
「候補が満たすべき条件」ではなく「候補が**避けられない**制約」である。
言い換えると、`L²` エネルギーと時間積分された `H¹` 散逸は有限時間内に
自動的に有界であり、特異点の直接的な発散指標にはできない。

## 3. 冪則 ansatz (S)

`t → T⁻` で

```text
N(t) = (T−t)^{−γ},    A(t) = (T−t)^{σ},
E_j(t) = A(t) · (λ_j / N(t))^{β}   (λ_j ≤ N(t)),   E_j(t) = 0  (λ_j > N(t)),
```

を仮定する(`γ` = 帯域幅指数、`σ` = ピークシェルのエネルギー指数、
`β` = ピークから低波数側へのスペクトル勾配)。`λ_j = N·2^{−m}`(`m ≥ 0`)と
書けば `E_j = A·2^{−βm}` で、以下の和はすべて等比級数になる。

**これは仮定である。** 対数補正、複数コア、非冪則、シェル間の非自明な相関は
この ansatz の外にあり、本書は何も言わない(§6)。

---

## 4. 4 つの必要条件

### 4.1 エネルギー有界 ⟹ `β > 0` かつ `σ ≥ 0`

```text
E = Σ_{m≥0} A·2^{−βm} = A/(1 − 2^{−β})   (β > 0 で収束)
```

`β ≤ 0` では級数が発散し (N-1) に反する。収束する場合 `E ≍ A = (T−t)^σ` で、
`t → T` で有界であるためには **`σ ≥ 0`**。

### 4.2 散逸有限 ⟹ `σ − 2γ > −1`

```text
Σ_j λ_j² E_j = A Σ_{m≥0} (N·2^{−m})² 2^{−βm} = A N² /(1 − 2^{−(2+β)}) ≍ A N².
```

よって

```text
∫₀ᵀ A(t)N(t)² dt ≍ ∫₀ᵀ (T−t)^{σ−2γ} dt < ∞  ⟺  σ − 2γ > −1.      (4.1)
```

### 4.3 臨界ノルム発散 ⟹ `σ < γ`

Bernstein 不等式 `‖u_j‖_{L³} ≲ λ_j^{1/2}‖u_j‖_{L²}` と三角不等式から

```text
‖u(t)‖_{L³} ≲ Σ_j λ_j^{1/2} E_j^{1/2} = ‖u(t)‖_{Ḃ^{1/2}_{2,1}}.       (4.2)
```

ansatz (S) の下では

```text
Σ_j λ_j^{1/2}E_j^{1/2} = A^{1/2} N^{1/2} Σ_{m≥0} 2^{−m(1+β)/2}
                       ≍ A^{1/2}N^{1/2} = (T−t)^{(σ−γ)/2}.
```

Escauriaza–Seregin–Šverák の端点正則性定理により、
`sup_{t<T}‖u(t)‖_{L³} < ∞` なら `T` は特異時刻ではない。(4.2) の右辺が有界なら
左辺も有界だから、**特異点が起こるためには**

```text
(σ − γ)/2 < 0  ⟺  σ < γ.                                            (4.3)
```

> **引用の明示**: ESS 端点定理は本書で証明していない。
> `docs/known_obstructions.md` §4.2 の管理下にあり、Lean 最終経路へ載せるなら
> 忠実な形式化か明示的に監査された定理インタフェースが必要である
> (`docs/final_target.md` §4 の `F-11`)。**未証明の project 固有 axiom として
> 挿入してはならない。**

### 4.4 帯域幅発散 ⟹ `γ > 0`

[track_f_finite_mode_nogo.md](track_f_finite_mode_nogo.md) Corollary 2 の対偶。
`γ = 0`(帯域幅が有界)は固定有限モード no-go で閉じている。

## 5. 実現可能領域と no-go 領域

### Proposition 1(実現可能領域)

4 条件を連立すると

```text
γ > 0,   β > 0,   max(0, 2γ − 1) < σ < γ  (σ = 0 は 2γ<1 のときのみ許容).
```

下端が上端を下回るためには `max(0, 2γ−1) < γ`、すなわち `2γ − 1 < γ` かつ
`0 < γ`。ゆえに

> **実現可能領域**
> ```text
> 0 < γ < 1,    β > 0,    max(0, 2γ − 1) ≤ σ < γ
> ```
> ただし下端 `σ = max(0,2γ−1)` が実際に許容されるのは `γ < 1/2` の場合のみ
> (そこでは下端が非狭義条件 `σ ≥ 0` 由来だから)。`γ ≥ 1/2` では
> 下端は狭義条件 (4.1) 由来なので到達不能。

### Proposition 2(no-go 領域)

次のいずれかを満たす冪則候補は**存在しない**。

| no-go 条件 | 破れる必要条件 |
|---|---|
| `γ ≤ 0`(帯域幅が有界) | 固定有限モード no-go(§4.4) |
| `β ≤ 0`(スペクトルがピークから増大しない) | エネルギー有界(§4.1) |
| `σ < 0` | エネルギー有界 (N-1) |
| `σ ≤ 2γ − 1` | 散逸有限 (N-2) |
| `σ ≥ γ` | 臨界ノルムが発散しない ⟹ ESS で正則 |

### Proposition 3(帯域幅の上限、**仮定付き**)

> **現在の shell ansatz と非退化仮定の下で `γ ≥ 1` は排除される。**

証明: `σ > 2γ−1` と `σ < γ` を同時に満たすには `2γ−1 < γ`、すなわち `γ < 1`。∎

**適用範囲を誤らないこと。** この排除は §3 の冪則 ansatz (S) と、
そこで暗黙に置いた**非退化仮定**の下でのみ成り立つ。具体的には
(a) シェルスペクトルが単一の冪 `β` で表せること、
(b) ピーク波数が単一の `N(t)` で表せること(多重コアなし)、
(c) 対数補正がないこと、(d) `β` が時間に依存しないこと、
(e) 定数 `≍` に隠れた因子が `t→T` で発散しないこと。
これらのいずれかが破れる候補について本書は**何も言わない**。

これは元導出の主結果だった。`γ<1` 自体は有限-floor修正後にも残るが、
`β>0` と三角領域だけを探索空間全体とみなすことは上記訂正により撤回する。

### 系(古典的自己相似スケーリングの位置)

放物型自己相似 `N ~ (T−t)^{-1/2}` は `γ = 1/2`。このとき実現可能な `σ` は
`0 < σ < 1/2` の**開区間**で、境界 `σ = 0`(ピークシェルのエネルギーが一定)は
散逸積分が対数発散するため排除される。これは自己相似爆発の非存在
(`docs/known_obstructions.md` §1)の指数レベルでの影である。

## 6. 外力が高波数で無力であること(設計上の主結論)

Clay (C)/(D) の外力は `𝕋³×[0,∞)` 上 `C^∞` である。コンパクト時間区間
`[0,T]` 上でその Fourier 係数は任意の多項式より速く減衰する:

```text
‖f_j(t)‖_{L²} ≤ C_m λ_j^{−m}    (∀m ∈ ℕ, ∀t ∈ [0,T]).              (6.1)
```

これをシェル収支 (1.1) に入れると、シェル `j` への外力の寄与は

```text
|⟨u_j, f_j⟩| ≤ E_j^{1/2} C_m λ_j^{−m}
```

で、任意の `m` に対して成り立つ。すなわち

> **滑らかな外力は高シェルの収支で不可視である。** 高波数エネルギーは
> すべて非線形フラックス `Π_j` が供給しなければならない。

帰結(**正確に述べる**): 滑らかな外力は高周波を直接供給できないが、低周波を制御して非線形カスケードを間接駆動する可能性は残る。
(6.1) が排除するのは **`⟨u_j,f_j⟩` という直接注入経路だけ**である。外力は
低周波シェルの振幅・位相・相対配置を自由に整形でき、その低周波場は
非線形 triad `Π_j` を通じて高シェルへエネルギーを運びうる。
**「外力の高周波係数が小さい」ことだけから外力の間接的効果を排除しては
ならない。** 外力の役割の分離と、その間接駆動が実際に成立しうるかの
模型検査は [cascade_toy_model.md](cascade_toy_model.md) で扱う。

### フラックス条件は(この粗さでは)拘束にならない

念のため確認しておく。`|Π_J| ≤ ‖u_J‖_{L²}‖Δ_J((u·∇)u)‖_{L²} ≲ λ_J E_J^{1/2}
‖u‖_{L^∞}‖u‖_{L²}` と `‖u‖_{L^∞} ≲ Σ_j λ_j^{3/2}E_j^{1/2} ≍ A^{1/2}N^{3/2}`
(β > −3)より `|Π_J| ≲ N^{5/2}A·E^{1/2}`。一方ピークシェルが必要とする
フラックスは `≳ νN²A`。比は `N^{1/2}/ν → ∞` なので、**この粗い上界は
`(γ,σ)` に追加の制約を与えない**。より鋭いフラックス評価が必要なら別途
設計する。本書は追加制約を捏造しない。

## 7. 限界(何を証明していないか)

1. **これは必要条件であって存在ではない。** 実現可能領域内の点は
   Navier–Stokes の解ではない。`docs/type_ii_scaling_constraints.md` の
   Type-II 走査と同じ性質のものである。
2. 冪則 ansatz (S) の外は覆っていない: 対数補正、複数コア、
   シェル間の相関、`E_j` の非単調な形状、時間依存する `β`。
3. §4.3 は **ESS 端点定理の引用**に依存する。未証明・未形式化。
4. `ℝ³` 版では低波数シェルの扱いが変わる(`λ_j → 0` の側が非有界)。
   Clay 条件 (4) の急減衰があれば低シェルの寄与は有限だが、
   本書は `𝕋³` でのみ導出した。`ℝ³` への移植は未実施。
5. (1.1)(1.2) は形式的な恒等式として使った。二進射影の可換性・
   Bernstein 不等式の定数は標準的だが、本リポジトリでは未監査である。
6. Lean 形式化はしていない。F-12 が (1.2) の Fourier 版を覆うのみ。

## 8. 探索設計への具体的帰結

1. **固定有限モード探索を再開しない。** 証明により空。
2. **`γ ≥ 1` の候補族を設計しない。** Proposition 3 により空。
3. 探索するなら `0 < γ < 1`、`max(0,2γ−1) ≤ σ < γ`、`β > 0` の三角領域内で、
   かつ **`σ/(2γ)` より高い Sobolev 指数**で診断量を取ること
   (`ShellExponents.sobolev_exponent_threshold`)。`L²` と `H¹` は
   §2 により原理的に発散しないので、診断量として無意味である。
4. 外力設計に**直接**の高波数注入を期待しない(§6)。ただし低周波整形を
   通じた**間接駆動**は排除されていないので、設計自由度としては残る。
   実際に間接駆動でカスケードが持続しうるかは
   [cascade_toy_model.md](cascade_toy_model.md) の有限 triad 模型で判定する。
5. 次に導出すべきは、`Π_j` の**鋭い**上界(現在の粗い評価は拘束にならない)と、
   対数補正を許した場合の領域の変化である。
