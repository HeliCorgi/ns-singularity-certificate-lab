## 0. 何のための文書か

(C)/(D) を狙って次を提案している。

> 特異 ansatz `u,p` を設計し、`f = ∂t u + (u·∇)u − νΔu + ∇p` が特異時刻を
> 越えて滑らかになるように主要特異項を相殺する。

1. divergence-free 周期 Fourier ansatz を定義、

6. **存在しなければ、その ansatz 族の no-go 条件を証明・Lean 化**

## 1. Ansatz 族の定義

有限対称モード集合 `S ⊂ ℤ³`(`S = −S`)に対し

```text
V_S := { u : 𝕋³ → ℝ³ |  u(x) = Σ_{k∈S} a_k e^{2πi k·x},
                         a_{−k} = conj(a_k),   k · a_k = 0  (∀k∈S) }
```

とおく。`V_S` は実有限次元(`dim_ℝ V_S = Σ_{±pair} 4`、零モードがあれば `+3`)で、
その要素はすべて実数値・`C^∞`・`ℤ³` 周期・発散ゼロである。

**Track-F 有限モード ansatz**とは、ある有限 `S` と `T ∈ (0,∞)` に対し

* `u : [0,T) → V_S` が `C¹` 曲線、
* 各 `t` で `p(t,·) ∈ C¹(𝕋³)`、
* `f := ∂_t u + (u·∇)u − νΔu + ∇p`

であって、`u` が `t → T⁻` で滑らかに延長できないもの、を言う。

`u` の Fourier 台は `S` に固定されるが、`(u·∇)u` の台は `S+S` へ広がる。
`S` の外のモードは **すべて `f` が担う**。これは制限ではなく、Track F の
設計そのものである(`f` は自由に選べる)。

## 2. Lemma 1 — 非線形項のエネルギー中立性 (T-1)

> **Lemma 1.** 任意の実数値・発散ゼロな三角多項式 `u`(すなわち任意の
> `u ∈ V_S`)に対し `⟨u, (u·∇)u⟩ = 0`。

**証明(積分による)。**
`u_i u_j ∂_j u_i = u_j ∂_j(|u|²/2)` を `𝕋³` 上で積分し、周期性から境界項なしで
部分積分すると `−∫ (∂_j u_j)|u|²/2 = 0`。∎

**証明(Fourier 展開による — 機械検証されるのはこちら)。**
`∫_{𝕋³} e^{2πi(k+l+m)·x} dx = δ_{k+l+m,0}` より

```text
⟨u,(u·∇)u⟩ = 2πi · Σ_{k+l+m=0,  k,l,m ∈ S} (a_l·m)(a_k·a_m)          (2.1)
```

(内側の積はいずれも複素双線型積)。(2.1) の和で `k ↔ m` を入れ替えて元の和に
加えると

```text
2 Σ (a_l·m)(a_k·a_m) = Σ (a_k·a_m) (a_l·(k+m)) = − Σ (a_k·a_m)(a_l·l) = 0,
```

最後の等号は発散ゼロ条件 `l · a_l = 0` による。∎

**機械検証**: `src/ns_certificate_lab/galerkin_obstruction.py` の
`verify_trilinear_cancellation` は、各 `k ∈ S` の横断部分空間
`k^⊥ = {v : k·v = 0}` の **整数**基底(`k × e_i` の独立な 2 本)で
`a_k` を座標付けし、(2.1) の右辺を `ℤ[i]` 係数の 3 次多項式へ完全展開して、
**全単項式係数がゼロであることを確認**する。浮動小数点は一切使わない。
これは有限個の整数等式の検査であり、Lemma 1 の当該 `S` に対する
厳密な機械検証である(すべての `S` に対する一般証明は上の 2 行である)。

## 3. Theorem 1 — 有限モード ansatz は特異にならない

> **Theorem 1.** `S ⊂ ℤ³` を有限対称集合、`ν ≥ 0`、`T ∈ (0,∞)` とし、
> `u, p, f` を §1 のとおりとする。さらに `f ∈ L¹((0,T); L²(𝕋³))` と仮定し
> `M(t) := ∫_0^t ‖f(s)‖ ds`、`M := M(T⁻) < ∞` とおく。このとき
>
> **(i) (a priori bound)** すべての `t ∈ [0,T)` で
> ```text
> ‖u(t)‖ ≤ ‖u(0)‖ + M(t) ≤ ‖u(0)‖ + M.
> ```
> **(ii) (全ノルムの有界性)** `R_S := max_{k∈S}|k|` とおくと、
> すべての `s ≥ 0` と多重指数 `α` に対し
> ```text
> sup_{t<T} ‖u(t)‖_{H^s}   ≤ (1 + 4π²R_S²)^{s/2} (‖u(0)‖ + M),
> sup_{t<T} ‖∂^α u(t)‖_{L^∞} ≤ (2πR_S)^{|α|} √|S| (‖u(0)‖ + M).
> ```
> **(iii) (延長)** さらに `Πf : [0,T'] → V_S` がある `T' > T` について連続なら
> (`Π` は `V_S` への `L²` 直交射影)、`u` は `[0,T+δ)` 上の `C¹` な
> `V_S` 値関数へ延長される(`δ > 0`)。`Πf` が `C^∞` なら延長も `C^∞`。
> とくに **`u` は `T` で特異にならない**。

### 証明

**(i)** `E(t) := ½‖u(t)‖²` は `C¹` で `E' = ⟨u, ∂_t u⟩`。定義から
`∂_t u = f − (u·∇)u + νΔu − ∇p` であり、各項を `u` と対にすると

* `⟨u, (u·∇)u⟩ = 0`(Lemma 1)、
* `⟨u, ∇p⟩ = −∫ (div u) p = 0`(周期性 + 発散ゼロ)、
* `⟨u, νΔu⟩ = −ν‖∇u‖² ≤ 0`、

したがって

```text
E'(t) = ⟨u,f⟩ − ν‖∇u‖² ≤ ‖u(t)‖ · ‖f(t)‖.                       (3.1)
```

`ε > 0` に対し `y_ε(t) := (‖u(t)‖² + ε)^{1/2} > 0` とおくと
`y_ε' = E'/y_ε ≤ ‖u‖‖f‖/y_ε ≤ ‖f‖`(`‖u‖ ≤ y_ε` による)。
積分して `y_ε(t) ≤ y_ε(0) + M(t)`、`‖u(t)‖ ≤ y_ε(t)` と `ε ↓ 0` で (i)。∎

> 注意: `ν` も `S` も (i) には現れない。散逸は助けるだけであり、
> 非線形項は Lemma 1 により**完全に無害**である。

**(ii)** `V_S` 上で `‖u‖_{H^s}² = Σ_k (1+4π²|k|²)^s |a_k|² ≤
(1+4π²R_S²)^s ‖u‖²`(Parseval)。また
`|∂^α u(x)| ≤ Σ_k (2π)^{|α|}|k^α||a_k| ≤ (2πR_S)^{|α|} Σ_{k∈S}|a_k|
≤ (2πR_S)^{|α|}√|S| ‖u‖`(`|k^α| ≤ |k|^{|α|}` と `S` 上の Cauchy–Schwarz)。
(i) と合わせて (ii)。∎

**(iii)** `u(t) ∈ V_S` かつ `u` が `V_S` 値 `C¹` 曲線なので `∂_t u(t) ∈ V_S`、
よって `Π∂_t u = ∂_t u`。`Δ` は `V_S` を保つので `ΠΔu = Δu`。
勾配場は `𝕋³` 上で発散ゼロ場に直交するから `Π∇p = 0`。したがって定義式に
`Π` を当てると、`V_S` の実正規直交基底に関する座標 `c(t) ∈ ℝ^{dim V_S}`
(`|c(t)| = ‖u(t)‖`)について**閉じた常微分方程式**

```text
c'(t) = g(t) + B(c(t), c(t)) + A c(t),
  g(t) := Πf(t) の座標,  B := −Π∘(双線型移流),  A := νΔ|_{V_S}(対角・負半定値)
                                                                  (3.2)
```

が得られる。(3.2) は `t` について連続、`c` について多項式(局所 Lipschitz)
なので、初期値 `c(0)` を通る最大解が一意に存在し、その最大存在時刻 `T_max`
について「`T_max < T'` ならば `|c(t)| → ∞ (t → T_max⁻)`」が成り立つ。
(i) により `|c(t)| = ‖u(t)‖` は `[0,T)` 上有界だから `T_max > T`。
一意性より `c|_{[0,T)}` はこの最大解の制限であり、`u` は `[0,T+δ)` へ延長
される。`g ∈ C^∞` なら (3.2) から `c ∈ C^∞` が bootstrap で従う。∎

> (3.2) は **近似ではない**。Track-F ansatz は `u(t) ∈ V_S` を要求し、`S` の外の
> モードは全部 `f` が担うので、`Π` を当てた式は ansatz の厳密な発展則である。

## 4. Corollary — Clay (C)/(D) への帰結

> **Corollary 1 (周期、Clay (D))。** 有限モード ansatz は Clay (D) 反例の
> 破綻解になれない。Clay (D) は `f` が `𝕋³×[0,∞)` 上 `C^∞` であることを要求し、
> これは Theorem 1 (iii) の仮定を満たすから、`u` は `T` を越えて滑らかに
> 延長され、破綻しない。

> **Corollary 2 (帯域幅)。** ある `N < ∞` が存在して、すべての `t ∈ [0,T)` で
> `u(t)` の Fourier 台が `{|k| ≤ N}` に含まれるなら、`u` は `T` で破綻しない
> (`S := {k ∈ ℤ³ : |k| ≤ N}` に Theorem 1 を適用)。
> 対偶: **Track-F 反例の速度場は `t → T⁻` で Fourier 帯域幅が非有界でなければ
> ならない。**

> **Corollary 3 (全空間、Clay (C))。** `V ⊂ C^∞(ℝ³;ℝ³)` を有限次元実線型空間で、
> 各要素が発散ゼロかつ急減衰(Clay 条件 (4))とする。`u : [0,T) → V` が `C¹`、
> `p(t,·)` が有界かつ `∇p(t) ∈ L²`、`f := ∂_t u + (u·∇)u − νΔu + ∇p` が
> `L¹((0,T);L²(ℝ³))` なら Theorem 1 (i)(iii) の証明はそのまま通り
> (急減衰により部分積分の境界項が消え、`⟨v,∇p⟩ = 0` が `v ∈ V` で成立)、
> `u` は `T` で破綻しない。ノルム同値は `V` が有限次元であることのみによる。

**Corollary 1–3 が閉じる探索空間。** §6「優先候補A」の step 1–5、すなわち
「低次 divergence-free Fourier ansatz + 有限個の時間依存係数」の記号探索は、
**その定義により Corollary 1/2 の適用範囲に完全に含まれる**。ゆえに探索結果は
必ずゼロ件であり、実行する価値がない。より一般に、有限個の記号的自由度で
表される任意の ansatz(有限モード、有限次元 profile 空間、有限個の基底関数の
時間依存線形結合)は Corollary 3 で閉じる。

## 5. 副産物 — 任意の Track-F 反例が満たすべき必要条件

Theorem 1 (i) の証明のうち、有限次元性を使っていない部分は一般の
(無限モード)ansatz にもそのまま適用できる。`u` を `t < T` で滑らかな
発散ゼロ場、`f` を Track-F 残差、`f ∈ L¹((0,T);L²)` とすると (3.1) から:

**(N-1) エネルギー有界。** `sup_{t<T} ‖u(t)‖_{L²} ≤ ‖u(0)‖_{L²} + M < ∞`。
すなわち **Clay (C)/(D) 反例の特異点はエネルギーノルムには見えない**。
Clay 条件 (7)(有界エネルギー)は自動的に満たされてしまうので、
「エネルギーが発散する反例」という設計方針は端から誤りである。

**(N-2) 総散逸有限。** (3.1) を `[0,T)` で積分して
```text
ν ∫_0^T ‖∇u(t)‖² dt ≤ ½‖u(0)‖² + (‖u(0)‖ + M) · M < ∞.
```
すなわち `∇u ∈ L²_t L²_x`。したがって特異性は `L²_tH¹_x` にも見えない。

**(N-3) 臨界ノルムの発散。** (N-1)(N-2) から、破綻は臨界ノルムでのみ起こる。
Ladyzhenskaya–Prodi–Serrin 条件により、`T` が特異時刻であるためには
`2/p + 3/q = 1`(`q > 3`)を満たすすべての `(p,q)` で
`‖u‖_{L^p_t L^q_x([0,T))} = ∞` が必要である(**引用**であり本書では未証明。
`docs/known_obstructions.md` の管理下)。

(N-1)〜(N-3) は本リポジトリの Track U 側で既に確立している臨界 `L³` 障害
(`docs/research_notes/critical_l3_obstruction.md`)と**同じ結論を外力ありの
場合へ拡張**する。外力を許しても、破綻は劣臨界ノルムでは起こり得ない。

## 7. 先行研究との関係(新規性の主張なし)

Theorem 1 (i) は **Galerkin 近似の大域存在**という古典的事実の言い換えである。
Leray (1934) / Hopf (1951) による Leray–Hopf 弱解の構成は、まさに
「有限次元 Galerkin 系はエネルギー恒等式により大域可解」という補題の上に
立っている。本書の寄与は新しい定理ではなく、

1. その古典的事実が **Track F の ansatz 探索空間をちょうど空にする**という
   接続を明示したこと、
2. Lemma 1 を当該モード集合に対し **厳密算術で機械検証**したこと、
3. Theorem 1 (i) の中核不等式を **Lean 4 で証明**したこと(§8)、

の 3 点である。`docs/known_obstructions.md` の方針(公表済み陰性空間は
実験ではなく引用として扱う)に従い、探索ラウンドは登録しない。
