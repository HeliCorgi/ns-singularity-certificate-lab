## 0. なぜ必要か

Gate 4 が保証したのは**自由空間ポテンシャルの値**だけである。その a posteriori
上界は最大値原理で内部へ伝播するが、**最大値原理は微分について何も言わない**。
一方、非線形時間発展が消費するのは微分である:

```text
u^r = −r ∂_zψ₁,   u^z = 2ψ₁ + r ∂_rψ₁,
```

さらに移流項がその微分を消費する。したがって全空間非線形入口には
**微分の tail 評価**が要る。本書はそれを Green 核の微分から独立に導く。
最大値原理は §3 の内部伝播でしか使わず、そこでも値についてのみ使う。

---

## 1. 記法と基本量

`X ∈ ℝ⁵`、`G₅(X) = c₅|X|^{−3}`、`c₅ = 1/(8π²)` は `−Δ₅` の基本解。
源 `ω` は `|Y| ≤ a` に台を持つ軸対称関数、`dV₅ = |S³|ρ³dρdζ`。

```text
M₅ = ∫ω dV₅,   P = ∫Y ω dV₅  (軸対称性より P = (0,0,0,0,P_z)),
I₁ = ∫|Y||ω|dV₅,   I₂ = ∫|Y|²|ω|dV₅.
```

評価点 `X` について `d := |X| − a > 0`。

---

## 2. Lemma A — Green 核の微分の**厳密な**斉次性定数

`G₅` は `(−3)` 斉次なので `D^mG₅` は `(−3−m)` 斉次である。ゆえに

```text
‖D^mG₅(Z)‖ = A_m |Z|^{−3−m}                                     (2.1)
```

が**恒等式**として成り立ち、`A_m` は純粋な数である(`‖·‖` は対称 `m` 重線型形式の
作用素ノルム)。閉形式の微分テンソルから:

| `m` | `D^m(|Z|^{−3})` の構造(`|Z|=1`) | `A_m/c₅` | 種別 |
|---:|---|---:|---|
| 0 | `1` | 1 | 厳密 |
| 1 | `−3Z_i` | 3 | 厳密 |
| 2 | `−3δ_{ij} + 15Z_iZ_j` | 12 | **厳密**(固有値 `12`(`Z` 方向)と `−3`(横断)) |
| 3 | `15(δZ+δZ+δZ) − 105ZZZ` | 150 | 三角不等式(sharp 値は 60) |
| 4 | `15(3δδ) − 105(6δZZ) + 945ZZZZ` | 1620 | 三角不等式 |
| 5 | `−315δδZ + 105(12δδZ) + 945(6+4)δZZZ − 10395ZZZZZ` | 21420 | 三角不等式 |

`A_1 = 3c₅` と `A_2 = 12c₅` は
[test_free_space_recovery.py](../../tests/test_free_space_recovery.py) が
5 次元核の差分から数値的にも確認する(相対 `1e-6` / `1e-4`)。
`m ≥ 3` は上界であり、`A_3` は真値の 2.5 倍保守的であることが分かっている。
**「ある定数」ではなく既知倍率の保守性である。**

## 3. Theorem B — 単極子打切りの全微分上界

> **Theorem B(単極子)。** `d = |X| − a > 0` のとき、`k = 0,1,2,3` について
> ```text
> |D^kψ_∞(X) − D^k(M₅G₅)(X)| ≤ A_{k+1} · I₁ / d^{4+k}.          (3.1)
> ```

**証明。** `ψ_∞(X) − M₅G₅(X) = ∫[G₅(X−Y) − G₅(X)]ω(Y)dY`。積分記号下で `k` 回
微分し(`X` は台の外なので被積分関数は滑らか)、平均値の定理を線分 `X − θY`
(`θ∈[0,1]`)に沿って適用すると

```text
|D^kG₅(X−Y) − D^kG₅(X)| ≤ |Y| · sup_{θ} ‖D^{k+1}G₅(X−θY)‖
                        ≤ |Y| · A_{k+1}/d^{4+k}
```

((2.1) と `|X−θY| ≥ |X|−a = d` による)。`|ω|` について積分して (3.1)。∎

> **Theorem B'(双極子)。** さらに `−P·∇G₅(X)` を引くと、2 次の Taylor 剰余から
> ```text
> |D^kψ_∞ − D^k(M₅G₅ − P·∇G₅)| ≤ ½ A_{k+2} · I₂ / d^{5+k}.      (3.2)
> ```

**どちらも最大値原理を使っていない。** 使ったのは Green 核の解析的微分と
Taylor 剰余だけである。

### 実測(`outputs/whole_space_gate5_v1`、閉形式参照解に対して)

| 打切り | `R` | `d` | 値誤差/上界 | 勾配誤差/上界 | Hessian 誤差/上界 |
|---|---:|---:|---:|---:|---:|
| monopole | 2.5 | 0.804 | 0.0087 | 0.0032 | 0.0005 |
| monopole | 4.0 | 2.304 | 0.0712 | 0.0449 | 0.0113 |
| monopole | 6.0 | 4.304 | 0.1507 | 0.1151 | 0.0351 |
| dipole | 2.5 | 0.804 | 0.0020 | 0.0003 | 0.0001 |
| dipole | 4.0 | 2.304 | 0.0322 | 0.0077 | 0.0025 |
| dipole | 6.0 | 4.304 | 0.0921 | 0.0269 | 0.0109 |

全 18 セルで比 `< 1`。上界は 7〜10⁴ 倍保守的で、遠方ほど鋭くなる。
指数も予測どおり: 距離を 2 倍にすると値は `2⁻⁴`、勾配は `2⁻⁵`、
Hessian は `2⁻⁶`(実測 4.000000/5.000000/6.000000)。

## 4. Theorem C — box 内部への伝播(内部楕円評価)

box `Ω` 上の切断解 `ψ_box` と `ψ_∞` の差 `e` は `L₅e = 0`、すなわち `ℝ⁵` 上
調和である。境界データ誤差を `ε₀ := sup_{∂Ω}|ψ_∞ − ψ_bc|` とすると:

* `k = 0`: 最大値原理から `|e| ≤ ε₀`。
* `k ≥ 1`: **内部楕円評価**から
  ```text
  |D^ke(X)| ≤ (n k / ρ)^k ε₀,   n = 5,  ρ = dist(X, ∂Ω).      (4.1)
  ```
  (`B_ρ(X) ⊂ Ω` 上調和な `h` について `|D^kh| ≤ (nk/ρ)^k sup_{B_ρ}|h|` という
  古典的評価。`k = 0` の場合だけが最大値原理である。)

`ε₀` は Theorem B の `k = 0` 版で供給できるので、これで**内部の全微分**が
抑えられる。速度への翻訳は `u^r = −r∂_zψ`、`u^z = 2ψ + r∂_rψ` から

```text
|δu| ≤ 2ε₀ + R_max · (5/ρ) ε₀.                                  (4.2)
```

### 限界(隠さずに書く)

1. **(4.1) は連続レベルの命題である。** 離散解はさらに離散化誤差を持ち、
   本書はそれを抑えない。半径行 `i=1` は M-matrix でないので離散最大値原理も
   離散内部評価もない。
2. `(5k/ρ)^k` は `ρ → 0` で急速に悪化する。実装の既定 `interior_radius` は
   `boundary_radius − max(dr,dz)` なので、**格子を細かくすると評価点が境界に
   近づき上界が悪化する**(実測: `nr=65,129,257` で `2.21e-4 → 4.50e-4 → 9.01e-4`)。
   これは実装の既定値の性質であって上界の欠陥ではないが、利用者は
   `interior_radius` を固定して比較しなければならない。
3. `a` は数値的な台半径であり、粘性拡散があると閾値を要する。閾値で落とした
   質量は `SourceMoments.neglected_fraction` として毎回報告する。
   **落とした質量が無視できない実行では、上界は成立しない。**

## 5. 独立検証経路 — Green 核の解析微分 + 求積

軸対称源に対し `S³` 平均は 1 次元積分に落ちる:

```text
K(r,z;ρ,ζ) = 4πc₅ ∫_{−1}^{1} (r²+ρ²−2rρt+(z−ζ)²)^{−3/2} √(1−t²) dt,
```

`∫_{S³}f(x̂·ŷ)dσ = |S²|∫_{−1}^1 f(t)√(1−t²)dt` による。重み `√(1−t²)` は
**第 2 種 Gauss–Chebyshev 求積**が厳密に一致する。`∂_r, ∂_z, ∂_{rr}, ∂_{zz},
∂_{rz}` はいずれも核を**解析的に微分**してから求積する。
ソルバも差分作用素も一切使わない。

実測(閉形式参照解に対する相対誤差、目標点は台の外):

| 格子 | `ψ` | `∂_r` | `∂_z` | `∂_{rr}` | `∂_{zz}` | `∂_{rz}` |
|---|---:|---:|---:|---:|---:|---:|
| 161×321 | 2.51e-07 | 2.26e-07 | 2.78e-07 | 2.16e-07 | 3.21e-07 | 3.74e-07 |
| 321×641 | 1.57e-08 | 1.41e-08 | 1.73e-08 | 1.35e-08 | 2.00e-08 | 2.33e-08 |

観測次数は全 6 成分で **4.00**(コンパクト台の滑らかな被積分関数に対する
台形則)。**適用範囲は源の台の外に限る**(内部では簡約核が特異になる)。
