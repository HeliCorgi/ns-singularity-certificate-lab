## 1. 方程式(E-11–E-14 との照合)

[Q] Eq. (2.1a)–(2.1d)(印刷どおりの符号):

```
u_{1,t} + u^r u_{1,r} + u^z u_{1,z} = 2 u_1 ψ_{1,z} + ν( u_{1,rr} + (3/r) u_{1,r} ) + ν u_{1,zz}   (2.1a)
ω_{1,t} + u^r ω_{1,r} + u^z ω_{1,z} = 2 u_1 u_{1,z} + ν( ω_{1,rr} + (3/r) ω_{1,r} ) + ν ω_{1,zz}   (2.1b)
        -( ∂_r² + (3/r)∂_r + ∂_z² ) ψ_1 = ω_1                                                      (2.1c)
        u^r = -r ψ_{1,z} ,   u^z = 2 ψ_1 + r ψ_{1,r}                                               (2.1d)
```

- E-11–E-14 と符号込みで**完全一致**。(2.1b) の \(2u_1u_{1,z}=\partial_z(u_1^2)\)
  は E-12 の源泉項と同値。
- [X] 「L5」という名称はこの論文に存在しない(演算子は常に書き下し)。
  L5 は本リポジトリの記法である。
- [Q] 循環: \(\Gamma=ru^\theta=r^2u_1\) は
  \(\Gamma_t+u^r\Gamma_r+u^z\Gamma_z=\nu(\Delta-(2/r)\partial_r)\Gamma\) を満たし
  \(\|\Gamma(t)\|_\infty\le\|\Gamma_0\|_\infty\)(§3.5.3)。E-23 と整合。

## 2. 領域と対称性(E-28)

- [Q] 半径 \(r\in[0,1]\)、壁 \(r=1\) で no-slip/no-flow、\(z\) 周期 1。
- [Q] 計算領域は半周期 \(D_1=\{(r,z):0\le r\le1,\ 0\le z\le1/2\}\)
  (四半分周期ではない)。
- [P] \(u_1,\omega_1,\psi_1\) は \(r\) 偶・\(z\) 奇(周期 1 と合わせて
  \(z=1/2\) についても奇)。
- [Q] 「\(\omega_1\) の奇性は \(\omega_1\) 方程式の vortex stretching 項を
  通じて動的に誘導される」— つまり対称性は初期値の性質+力学保存。
- [Q] \(u^r=0\)(\(r=0,1\))、\(u^z=0\)(\(z=0,1/2\))で \(D_1\) の境界は
  "impermeable walls" として振る舞う。

## 3. 境界条件(E-27, E-31)

### 軸 r=0

[Q] Eq. (2.3): \(u_{1,r}(t,0,z)=\omega_{1,r}(t,0,z)=\psi_{1,r}(t,0,z)=0\)。
[P] 偶対称条件。HH21 では ghost 反射 \(v_{-1,j}=v_{1,j}\) で実装。

### 壁 r=1(再現の急所)

| 量 | 条件 | 出典 |
|---|---|---|
| \(\psi_1\) | \(=0\) | Eq. (2.4)(no-flow) |
| \(\partial_r\psi_1\) | \(=0\) | \(u^z=2\psi_1+r\psi_{1,r}=0\) と (2.4) から導出 |
| \(u_1\) | \(=0\) | Eq. (2.5)(\(u^\theta=ru_1=0\) から) |
| \(\omega_1\) | \(=-\psi_{1,rr}\) | Eq. (2.5)— **Thom 型渦度境界条件**、値の指定ではない |

[Q] 実装方針(§2): "We will enforce the no-slip boundary condition for
\(\omega_1\) as a vorticity boundary condition by discretizing
\(\omega_1(t,1,z)=-\psi_{1,rr}(t,1,z)\) and imposing \(\psi_{1,r}(t,1,z)=0\)."

[P] Poisson 問題は単一 Dirichlet 条件 \(\psi_1(1,z)=0\) で解く。
\(\psi_{1,r}(1,z)=0\) は渦度境界条件の生成にのみ使う。両方を Poisson に
課すと過剰決定(E-27 の監査警告)。

### z 境界

[P] 周期 1 + \(z=0,1/2\) での奇対称。HH21 実装は
\(v_{i,-1}=-v_{i,1}\)、\(v_{i,m+1}=-v_{i,m-1}\)。

## 4. 初期値と粘性(E-29, E-30)

[Q] Eq. (2.2):

\[
u_1(0,r,z)=\frac{12000(1-r^2)^{18}\sin(2\pi z)}{1+12.5\sin^2(\pi z)},
\qquad \omega_1(0,r,z)=0.
\]

- [Q] 「flow is completely driven by large swirl initially… The other two
  velocity components are set to zero initially.」
- [Q] 「ごく早期には \(u_1\) の最大値は実際に**減少**する」— 定性的な
  早期再現ターゲット。
- [X] \(\|u_1(0)\|_\infty\)、\(\|\omega(0)\|_\infty\) の数値は論文にない。
- [D] 監査者導出(E-29b、実装時に数値最大化で再検証すること):
  \(\|u_1(0)\|_\infty=3265.9863\ldots\) at \((0,0.0845843)\);
  \(\|\omega(0)\|_\infty=24000\pi\cdot37^{-1/2}\cdot(36/37)^{18}=7569.62\ldots\)
  at \((1/\sqrt{37},0)\)(\(\omega^r\) 成分)。オーケストレータが Taylor
  展開と停留点計算で独立検算済み(z=0 近傍で \(|\omega|^2\) の \(z^2\) 係数が
  負であることを含む)。

### 粘性は二段階 [Q]

「\(\nu=5\times10^{-4}\) で短時間 \(t_0=0.00227375\) まで解き、その後
\(\nu\) を \(5\times10^{-3}\) へ増やすのが最適に近い成長率を与える」(§3)。
§1 の「relatively large viscosity \(\nu=5\times10^{-3}\)」だけを読むと
誤実装する。さらに [Q] §3.3.2: \(t_0\) 以後の粗格子は 1536² 解からの
**restart**(初期値扱い)であり、\(t=0\) からの独立 run ではない。

## 5. 数値手法

### 本論文に記載(§1.4, §2, App. A)

- [Q] 空間 2 次有限差分、時間 2 次陽的 Runge–Kutta、適応時間刻み
  (最小 \(O(10^{-15})\))、全体 2 次精度。
- [Q] \(r,z\) の適応 mesh 写像(解析的密度関数、最小格子幅 \(O(10^{-8})\)、
  phase 0–3 の構成、パラメータは動的調整)。App. A.2 に NS 用の
  全パラメータ(period 1/2/3、\(T_1=0.002191729\)、\(T_2=0.002261605\)
  ほか)。
- [Q] 「手法の詳細は [Hou–Huang arXiv:2102.06663] の Appendix A を参照」。

### 委譲先 HH21 に記載(本論文ではない点に注意)

- [Q] Poisson: 2 次 **B-spline Galerkin**(Luo–Hou 由来)、重み
  \(w(\rho)=1-\rho^2\) で \(\psi_1(1,z)=0\) を符号化、6 点 Gauss–Legendre、
  スパース SPD を MATLAB solver で解く。
- [Q] 微分: 写像座標 \((\rho,\eta)\) の 2 次中心差分+解析的 Jacobian
  (\(r_{\rho\rho}\) は解析式)。壁近傍外挿
  \(v_{n+1,j}=3v_{n,j}-3v_{n-1,j}+v_{n-2,j}\)。
- [Q] CFL: 対流・粘性それぞれ CFL 数 0.1、
  \(\delta t=\min\{\delta t_1,\delta t_2\}\)、1 step の最大値相対成長 <1%。
- [Q] 時間積分: 2 段 2 次陽的 RK(Heun、\(c=(0,1)\), \(a_{21}=1\),
  \(b=(1/2,1/2)\))。
- [Q] mesh 間補間: \((\rho,\eta)\) 空間の 4 次区分多項式。
- [Q] mesh 密度関数: \(q_b(x)=(1+x)^b/(1+(1+x)^b)\)、\(b=60\)、
  方向あたり 7 パラメータ。
- filter: HH21 は一様 \(LPF_{0.1}\)+尾部 \(c_L\)+\(\psi\) 系への
  \(LPF_1\) を記載。

### ⚠ 真正の曖昧さ(人間への確認事項)

[Q] Hou21 §1.3 は「尾部に filter を適用する必要はない」と述べ尾部 filter
\(c_L\) を除外するが、一様 \(LPF_{0.1}\)(\(u_1,\omega_1\))と \(LPF_1\)
(\(\psi_1,\psi_{1,r},\psi_{1,z}\))を保持しているかは**本文から決定不能**。
再現の分岐点。

### [X] 取得不能

軸での \((3/r)\partial_r\) の離散処理、移流の風上化の有無、mesh 更新
トリガの閾値("a certain value")。

## 8. 壁の役割と "potentially singular" の位置づけ

- [Q] 「この特異性シナリオは境界上で起こる Hou–Luo シナリオとは異なる」。
- [Q] CKN 部分正則性により軸対称 NS の特異点は対称軸上に限られる —
  爆発は原点 \((0,0)\)(内部、軸上)で主張される。壁は容器であり
  特異点の場所ではない。
- [Q] Abstract: 「**some new numerical evidence** … **seem to** develop
  potentially singular behavior」。§3.4.1 の Remark は \(T\)・爆発率・定数の
  定量 fitting を明示的に放棄。
- [P] 監査者評価: 臨界 \(L^3\) 判定だけが数値上逆方向であり、論文の防御は
  「数値誤差の説明」であって「誤差を除去した計算」ではない。

## 9. v1 → v2 の結論反転(最重要の文脈)
