# Known obstructions and continuation criteria

## 0. 目的と適用範囲

本書は、数値候補が既知の正則性定理に直ちに反しないかを、実験前・実験中・証明書化前の三段階で検査するための台帳である。ここで「障害」とは特異点の非存在を一般に証明するものではなく、**特定の仮定を満たす候補を排除する定理**をいう。

基準とする物理問題は、粘性 \(\nu>0\) の全空間 Cauchy 問題

\[
\partial_t u+(u\cdot\nabla)u+\nabla p=\nu\Delta u,\qquad
\nabla\cdot u=0,\qquad x\in\mathbb R^3,\quad 0<t<T
\]

である。初期値 \(u_0\) は滑らか、発散ゼロ、軸対称で、有限エネルギーと無限遠での十分な減衰を持つものを探索対象とする。候補時刻 \(T<\infty\) までは古典解であり、\(T\) が最初の正則性喪失時刻である、という状況を想定する。この前提自体を数値計算だけで証明したことにはならない。

Navier–Stokes の自然な等方スケーリングは

\[
u_\lambda(x,t)=\lambda u(\lambda x,\lambda^2t),\qquad
p_\lambda(x,t)=\lambda^2p(\lambda x,\lambda^2t)
\]

である。速度の \(L^3_x\)、混合ノルム \(L_t^qL_x^p\) の
\(2/q+3/p=1\)、渦度の \(L_t^qL_x^p\) の \(2/q+3/p=2\) は尺度臨界である。

以下の「候補が外す必要がある仮定」は、物理問題の要件を捨ててよいという意味ではない。たとえば有限エネルギーや局所エネルギー不等式を外す候補は Clay 問題の反例候補として不適格である。したがって実際には、定理中の**相似形、Type I 上界、臨界可積分性**などを外す必要がある。

出典キーは [REFERENCES.md](../REFERENCES.md) に対応する。

## 1. 後方自己相似解の非存在

### 1.1 Nečas–Růžička–Šverák の \(L^3\) 非存在定理

候補時刻を \(T\)、定数 \(a>0\) として、Leray の厳密な一尺度後方自己相似形を

\[
u(x,t)=\frac{1}{\sqrt{2a(T-t)}}\,
U\!\left(\frac{x}{\sqrt{2a(T-t)}}\right)
\]

とする。このとき \(U\) は

\[
-\nu\Delta U+aU+a(y\cdot\nabla)U+(U\cdot\nabla)U+\nabla P=0,
\qquad \nabla\cdot U=0
\]

を満たす。

**正確な仮定。** \(U\in W^{1,2}_{\mathrm{loc}}(\mathbb R^3)\) が発散ゼロで、上のプロファイル方程式をコンパクト台を持つ滑らかな発散ゼロ試験関数に対して弱い意味で満たし、さらに
\(U\in L^3(\mathbb R^3)\) である。

**結論。** \(U\equiv0\)。

**探索空間への適用。** 本プロジェクトの滑らかな有限エネルギー候補が厳密な後方自己相似形で、自然な大域エネルギー等式を満たすなら、プロファイルは \(L^2\cap\dot H^1\subset L^3\) となるので排除される。したがって「固定された一尺度プロファイルを見つけるだけ」の探索は、目的と整合しない。

**候補が外す必要がある仮定。** 非自明候補は少なくとも、厳密な時間非依存一尺度相似形、または \(U\in L^3\) を外さなければならない。しかし有限エネルギー反例を目標にする限り、後者を意図的に外すのではなく、時間依存プロファイル、Type II、異方的多尺度、周期・準定常軌道などへ進むべきである。

**出典。** [NRS1996], Theorem 1。状態: **一次資料で確認済み**。

### 1.2 Tsai の有限局所エネルギー非存在定理

**正確な仮定。** 相似中心を平行移動して \(x=0\) とする。\(u\) が
\(Q_1(0,T)=B_1(0)\times(T-1,T)\) 上の Navier–Stokes の弱解で、
上記の厳密な Leray 後方自己相似形を持つ。さらに

\[
\operatorname*{ess\,sup}_{T-1<t<T}\int_{B_1(0)}|u(x,t)|^2\,dx
+
\int_{T-1}^{T}\int_{B_1(0)}|\nabla u|^2\,dx\,dt<\infty
\]

という有限局所エネルギー条件を満たす。半径と時間幅を一般の
正値に変えた版は、相似中心を含む放物円柱を Navier–Stokes
スケーリングでこの形へ正規化したものとしてのみ用いる。相似中心を含まない
任意の球での有限性だけでは、この定理の仮定にならない。

**結論。** \(u\equiv0\)。

同論文には、弱いプロファイル \(U\in W^{1,2}_{\mathrm{loc}}\cap L^q(\mathbb R^3)\) について、\(3<q<\infty\) なら \(U=0\)、\(q=\infty\) なら空間的定数、という結果もある。

**探索空間への適用。** suitable weak solution として局所エネルギー不等式を保ちたい候補は、厳密な後方自己相似形では非自明になれない。大域有限エネルギーを仮定しない局所候補であっても、この定理の射程に入る。

**候補が外す必要がある仮定。** 局所エネルギーを外す候補は反例として不適格になりうる。したがって外すべきなのは固定一尺度・時間非依存プロファイルという相似仮定である。

**出典。** [Tsai1998] および 1999 年の正誤表。状態: **一次資料で確認済み**。

## 2. Type I 特異点に対する制限

### 2.1 定義

速度の \(L^\infty\) に関する Type I 上界を

\[
\sup_{0<t<T}\sqrt{T-t}\,\|u(t)\|_{L^\infty(\mathbb R^3)}<\infty
\tag{TI}
\]

とする。局所版、圧力を含む版、他の尺度臨界量による定義もあるので、実験メタデータでは採用した定義を必ず記録する。ここでは (TI) を使う。

Type I は「自己相似である」と同義ではない。ただし blow-up 列を自然スケールで拡大すると bounded ancient solution を生成しやすく、Liouville 定理が障害になる。

### 2.2 軸対称 Type I 上界の排除

**正確な仮定。** \(v\) は \(\mathbb R^3\times[-T_0,0)\) 上の軸対称 Navier–Stokes 強解で、旋回成分を許す。ある有限定数 \(C_*\) について、次のいずれかを全空間・全時間で満たす。

\[
|v(x,t)|\le C_*|t|^{-1/2},
\tag{2.1}
\]

または、ある \(\varepsilon>0\) について

\[
|v(x,t)|\le C_*\,r^{-1+\varepsilon}|t|^{-\varepsilon/2}.
\tag{2.2}
\]

ここで \(r=\sqrt{x_1^2+x_2^2}\)。

**結論。** \(v\) は \(t=0\) で正則である。

**探索空間への適用。** 本プロジェクトはまさに軸対称・旋回あり・全空間の滑らかな解を対象にする。(2.1) は (TI) の pointwise 版なので、この探索空間で真の特異点があるなら、少なくともこの大域 Type I 上界を破る Type II 成長が必要である。有限領域計算で (2.1) が「破れた」ように見えても、外部領域を未計算なら定理との比較は未完了である。

**候補が外す必要がある仮定。** 軸対称性、強解性、全空間性は目標上維持する。従って候補は (2.1) および関連する (2.2) の上界を外れなければならない。数値的には
\(\sqrt{T-t}\|u(t)\|_\infty\) が解像度を上げても無界方向に成長することが必要条件だが、それだけで Type II 特異点の証明にはならない。

**出典。** [CSTY2009]。より早い混合上界
\(|v|\le C_*(r^2-t)^{-1/2}\) については [CSTY2008]。状態: **一次資料で確認済み**。

### 2.3 bounded ancient solution と Liouville 障害

**正確な仮定と結論。**

- 有限時刻特異点を持つ mild solution を最大点の速度スケールで拡大すると、非零の bounded ancient mild solution を部分列極限として生成する。
- bounded ancient weak solution が軸対称かつ旋回なしなら、空間的に軸方向定数
  \(u=(0,0,b_3(t))\) である。mild なら時間にも依らない。
- bounded ancient weak solution が軸対称で
  \[
  |u(x,t)|\le C/r
  \]
  を満たすなら \(u=0\)。

**探索空間への適用。** Type I 候補を拡大した極限がこれらのクラスに入れば非自明性と矛盾する。旋回が極限で消える候補、または尺度不変な \(C/r\) 上界を保つ候補は特に危険である。

**候補が外す必要がある仮定。** 非自明な ancient limit は旋回を保持し、既知の Liouville 仮定を外す必要がある。単に有限領域で非零プロファイルが見えるだけでは、全空間 ancient solution の存在・非自明性・無限遠条件を確認したことにならない。

**出典。** [KNSS2009], Proposition 6.1, Theorems 5.2, 5.3。状態: **一次資料で確認済み**。

## 3. BKM 型の継続条件

### 3.1 条件

一般次元では vorticity tensor を
\(\Omega_{ij}=\partial_i u_j-\partial_j u_i\) とし、三次元ではこれを
\(\omega=\nabla\times u\) と同一視する。より正確には、
\(1<p<\infty\), \(s>n/p+1\) とし、Bessel-potential 空間を

\[
L_s^p(\mathbb R^n)=(I-\Delta)^{-s/2}L^p(\mathbb R^n)
\]

と書く。発散ゼロ初期値から得られる

\[
u\in C([0,T);L_s^p(\mathbb R^n))
\]

の古典解を考える。[KatoPonce1988] の Navier–Stokes 継続判定により、

\[
\int_0^T\|\Omega(t)\|_{L^\infty(\mathbb R^n)}\,dt<\infty
\tag{BKM-NS}
\]

なら、この \(L_s^p\) 解は \(T\) を越えて継続できる。従って本プロジェクトの
\(n=3\), \(\nu>0\) の解の最大存在時刻 \(T_*\) が有限なら、

\[
\int_0^{T_*}\|\omega(t)\|_{L^\infty(\mathbb R^3)}\,dt=\infty
\]

が必要である。この主張は任意の Leray–Hopf 弱解について、そのまま正則性を
回復するという主張ではない。上記の \(L_s^p\) 古典解クラスと
\(s>n/p+1\) が継続判定の前提である。

**正確性についての注意。** [BKM1984] の原定理は Euler 方程式に対するものである。Navier–Stokes 版の直接出典には [KatoPonce1988] を用いる。本書は「BKM原論文が Navier–Stokes を直接扱った」とは主張しない。

**探索空間への適用。** 候補が有限時刻特異点なら、渦度最大値の単なる大きさではなく、その時間積分が発散しなければならない。

**候補が外す必要がある仮定。** 反例候補は (BKM-NS) の積分有限性を外す必要がある。数値上は、推定 \(T\) の変更、時間刻み、ピーク補間に安定な下限評価を作る必要がある。有限個の標本から improper integral の発散は証明できない。

**必須診断。**

\[
I_{\mathrm{BKM}}(t)=\int_0^t \|\omega(s)\|_\infty\,ds,\qquad
\beta_\omega(t)=(T-t)\frac{d}{dt}\log\|\omega(t)\|_\infty .
\]

\(\|\omega(t)\|_\infty\sim C(T-t)^{-\alpha}\) なら
\(\beta_\omega(t)\to\alpha>0\) となる規約である。
\(I_{\mathrm{BKM}}\) は複数の時間積分則で計算し、\(\beta_\omega\) は局所回帰窓を変えて安定性を調べる。

**出典。** Euler の原型 [BKM1984]、Navier–Stokes の直接出典
[KatoPonce1988]。渦度混合ノルム版との整合は [BdV1995]。状態:
**原型と Navier–Stokes の適用範囲を区別して一次資料で確認済み**。

## 4. Serrin 型正則性条件

### 4.1 非端点

**正確な仮定。** \(u\) が \(\mathbb R^3\times(0,T)\) の Leray–Hopf 弱解で、

\[
u\in L^q(0,T;L^p(\mathbb R^3)),\qquad
\frac{2}{q}+\frac{3}{p}\le1,\qquad 3<p\le\infty
\tag{S}
\]

を満たす。有限 \(q\) の尺度臨界等号ケースを含む。

**結論。** \(u\) は \((0,T]\) で正則で、対応する強解と一致する。

### 4.2 臨界端点

**正確な仮定。**

\[
u\in L^\infty(0,T;L^3(\mathbb R^3)).
\tag{S3}
\]

**結論。** 解は正則である。

**探索空間への適用。** 真の特異候補なら、すべての Serrin 許容対 \((p,q)\) に対して対応するノルムが有限に留まることはできない。特に \(L^\infty_tL^3_x\) の有界性は排除される。

**候補が外す必要がある仮定。** 候補は少なくとも一つではなく、正則性を与える**どの**許容対についても有限性を証明されてはならない。実験では代表対

\[
(p,q)=(\infty,2),(9,3),(6,4),(4,8),(3,\infty)
\]

を追跡する。ここで順序は \((p_{\rm space},q_{\rm time})\) である。局所ノルムだけの増大を大域 (S) の破れと同一視しない。

**出典。** 非端点の古典形 [Prodi1959], [Serrin1962]、端点 [ESS2003]。状態: **一次資料で確認済み**。

## 5. 軸対称流に固有の既知正則性

### 5.1 旋回なし

**仮定。** 軸対称速度

\[
u=u^r(r,z,t)e_r+u^\theta(r,z,t)e_\theta+u^z(r,z,t)e_z
\]

で \(u^\theta\equiv0\)。初期値は軸に適合する滑らかな発散ゼロ有限エネルギーデータで、古典的 Cauchy 問題のクラスに属する。

**結論。** 古典的結果により大域正則である。構造的には
\(\omega^\theta/r\) が

\[
\partial_t(\omega^\theta/r)
+u^r\partial_r(\omega^\theta/r)
+u^z\partial_z(\omega^\theta/r)
=\nu\left(\partial_{rr}+\frac3r\partial_r+\partial_{zz}\right)(\omega^\theta/r)
\]

を満たし、最大値原理型の制御を受ける。

**探索空間への適用。** 旋回なし部分空間は特異点探索対象から除外する。候補は \(u^\theta\not\equiv0\) でなければならない。

**候補が外す必要がある仮定。** 外すべき仮定は「旋回なし」のみであり、軸正則性や有限エネルギーを外してはならない。

**出典。** [Ladyzhenskaya1968], [UY1968]。bounded ancient 版は [KNSS2009]。状態: **古典的結論と構造は確認済み**。原論文の関数空間を現代 Sobolev 記法へ逐語的に移す作業は **未確認** なので、厳密適用時に再監査する。

### 5.2 旋回量 \(\Gamma=ru^\theta\)

滑らかな軸対称 Navier–Stokes 解では

\[
\partial_t\Gamma+u^r\partial_r\Gamma+u^z\partial_z\Gamma
=\nu\left(\Delta-\frac2r\partial_r\right)\Gamma,
\qquad \Gamma|_{r=0}=0.
\]

適切な減衰・境界条件の下で最大値原理により
\(\|\Gamma(t)\|_\infty\le\|\Gamma(0)\|_\infty\)。

**探索空間への適用。** \(u_1=u^\theta/r=\Gamma/r^2\) の増大は、\(\Gamma\) 自体の増大を必要としない。軸への集中と軸正則性の両方を高精度で検査しなければならない。軸上の不正な \(\Gamma\neq0\) は偽特異点である。

**出典。** [CSTY2008], [CSTY2009], [KNSS2009] の軸対称方程式。状態: **一次資料で確認済み**。

### 5.3 特異点の位置

滑らかな軸対称解は \(r>0\) の領域では、円柱座標係数が非特異であり、既知の局所正則性論により潜在的特異点は対称軸上に限られる。これは「軸上に特異点が存在する」という結論ではない。

**探索空間への適用。** 物理座標で軸から離れたリングにだけピークがあり、そのリングが \(T\) まで軸へ近づかない候補は、有限時刻特異点候補として不整合である。一方、リング中心 \(R(t)\to0\) と厚さ \(\ell(t)\to0\) の二尺度は排除されていないため、両方を追跡する。

**出典。** [CSTY2008] の問題設定と部分正則性の参照、[CKN1982]。状態: **一次資料で確認済み**。

## 6. 有限エネルギー条件

### 6.1 Leray–Hopf クラス

発散ゼロの \(u_0\in L^2(\mathbb R^3)\) に対する Leray–Hopf 弱解は

\[
u\in L^\infty(0,T;L^2(\mathbb R^3))
\cap L^2(0,T;\dot H^1(\mathbb R^3))
\]

に属し、ほとんどすべての \(t\) について

\[
\frac12\|u(t)\|_2^2
+\nu\int_0^t\|\nabla u(s)\|_2^2\,ds
\le\frac12\|u_0\|_2^2
\tag{E}
\]

を満たす。

**結論と限界。** (E) は大域弱解の存在とエネルギー制御を与えるが、三次元での大域滑らかさ・一意性を与えない。有限エネルギーは Navier–Stokes スケーリングに対して超臨界であり、有限時刻の局所集中を単独では排除しない。

**探索空間への適用。** 反例候補は滑らかな有限エネルギー初期値から出発し、少なくとも \(t<T\) で (E) と整合しなければならない。有限領域の「エネルギー減少」は、境界流出による減少と粘性散逸を分離しない限り証拠にならない。

**候補が外す必要がある仮定。** 有限エネルギーを外す必要はなく、外してはならない。真の候補は有限エネルギーのまま、より強い正則性ノルムが発散しうる必要がある。

**出典。** [Leray1934], [CMI-NS]。状態: **一次資料で確認済み**。

## 7. 局所エネルギー条件

### 7.1 suitable weak solution

局所円柱 \(Q=\Omega\times(t_0,t_1)\) で

\[
u\in L^\infty_tL^2_x(Q)\cap L^2_tH^1_x(Q),\qquad
p\in L^{3/2}(Q)
\]

かつ分布の意味で方程式を満たす対 \((u,p)\) を考える。すべての非負
\(\phi\in C_c^\infty(Q)\) に対して

\[
\begin{aligned}
&\int |u(x,t)|^2\phi(x,t)\,dx
+2\nu\int_{t_0}^t\!\!\int |\nabla u|^2\phi\,dx\,ds\\
&\quad\le
\int_{t_0}^t\!\!\int
|u|^2(\partial_s\phi+\nu\Delta\phi)
+(|u|^2+2p)u\cdot\nabla\phi\,dx\,ds
\end{aligned}
\tag{LEI}
\]

を満たすものが suitable weak solution である（初期項を含む版ではそれも加える）。

**結論。** Caffarelli–Kohn–Nirenberg により内部特異集合の一次元放物型 Hausdorff 測度はゼロである。

**探索空間への適用。** (LEI) は孤立した時空点の特異性を排除しない。しかし候補を局所エネルギー解として compactness 極限へ渡す際の必須条件になる。厳密な後方自己相似候補は Section 1.2 により、この条件と両立して非自明にはなれない。

**候補が外す必要がある仮定。** 反例候補は (LEI) を外すのではなく満たすべきである。排除定理を避けるには厳密一尺度自己相似性を外す。

**出典。** [CKN1982], [Tsai1998]。状態: **一次資料で確認済み**。

## 8. 渦度の可積分性条件

### 8.1 臨界混合ノルム

全空間の発散ゼロ場で \(1<p<\infty\) なら、Biot–Savart/Riesz 変換により

\[
\|\nabla u\|_{L^p}\le C_p\|\omega\|_{L^p}.
\]

従って、Leray–Hopf 解が

\[
\omega\in L^q(0,T;L^p(\mathbb R^3)),\qquad
\frac2q+\frac3p\le2,\qquad \frac32<p<\infty
\tag{V}
\]

を満たせば正則である。等号は尺度臨界である。\(p=\infty,q=1\) は Section 3 の BKM 型端点として別扱いにする。

**結論。** (V) の有限性は \(T\) までの正則性を与える。

**探索空間への適用。** 真の候補では臨界渦度ノルムの少なくとも必要な発散が起きなければならない。エネルギー不等式が与える
\(\omega\in L^2_tL^2_x\) は
\(2/2+3/2=5/2>2\) で超臨界なので、(V) とは矛盾しない。

**候補が外す必要がある仮定。** 候補は (V) の有限性を外す必要がある。有限領域・離散格子上で得られた有限値は、大域・連続ノルムの有限性を意味しない。

**出典。** [BdV1995]、速度版 [Serrin1962]。状態: **一次資料の定理内容と Riesz 変換による全空間での帰結を確認済み**。

### 8.2 実験で保存する渦度診断

最低限、次を時系列で保存する。

- \(\|\omega(t)\|_{L^\infty}\) と \(I_{\mathrm{BKM}}(t)\)。
- \(p\in\{2,3,4,6,\infty\}\) の \(\|\omega(t)\|_{L^p}\)。
- 許容対ごとの累積量
  \[
  I_{p,q}(t)=\int_0^t\|\omega(s)\|_{L^p}^q\,ds.
  \]
- 全空間値、集中核内の局所値、外部領域値を分離したもの。
- 円柱座標の \(\omega^r,\omega^\theta,\omega^z\) と、Cartesian 再構成から独立に計算した \(\nabla\times u\) の差。

これらの増大は必要条件の数値的整合性検査にすぎず、発散の証明ではない。

## 8.5 外力ありの場合(Clay (C)/(D))に固有の障害

2026-07-29 第 3 便で本リポジトリ内において証明した障害。導出と証明は
[track_f_finite_mode_nogo.md](research_notes/track_f_finite_mode_nogo.md)、
中核不等式の Lean 形式化は `formal/NSSingularity/GalerkinNoBlowup.lean`(F-6)。

### 8.5.1 有限モード(有限次元)ansatz の除外

滑らかな外力 \(f\) を残差として定義する Track F 型の反例構成において、
速度場 \(u(t)\) が **固定した有限次元の発散ゼロ空間** \(V\) に留まるなら、
\(f\in L^1((0,T);L^2)\) のもとで

\[
\|u(t)\|_{L^2}\le\|u(0)\|_{L^2}+\int_0^t\|f(s)\|_{L^2}ds
\]

が成り立ち、\(V\) 上のノルム同値により全ての導関数が有界、さらに射影した
常微分方程式の延長により \(u\) は \(T\) を越えて滑らかに延長される。
すなわち **有限モード ansatz は特異にならない**。

対偶として: **Clay (C)/(D) 反例の速度場は \(t\to T^-\) で Fourier 帯域幅
(より一般に、張る有限次元部分空間の次元)が非有界でなければならない。**

これは Galerkin 近似の大域可解性(Leray 1934 / Hopf 1951)の言い換えであり、
新しい定理ではない。本書に載せる理由は、記号的 ansatz 探索の空間が
**この障害でちょうど空になる**という接続を運用ルールにするためである。

### 8.5.2 外力を許してもエネルギーでは破綻しない

同じエネルギー恒等式から、\(f\in L^1((0,T);L^2)\) を満たす任意の Track-F
反例について

\[
\sup_{t<T}\|u(t)\|_{L^2}<\infty,\qquad
\nu\int_0^T\|\nabla u(t)\|_{L^2}^2\,dt<\infty
\]

が従う(有限次元性は不要)。したがって Clay 条件 (7)(有界エネルギー)は
**外力を付けても自動的に満たされてしまい**、破綻は劣臨界ノルムでは
起こり得ない。Serrin/LPS 臨界ノルムの発散(§4)が依然として必要である。

## 9. 候補受入れ前の障害フィルター

候補を「証明書化対象」に昇格する前に、次の全項目を満たす。

| ID | フィルター | 不合格条件 |
|---|---|---|
| O-SS | 後方自己相似 | 時間独立一尺度プロファイルで、有限局所エネルギーまたは \(L^3\) を満たす |

| O-BKM | BKM 型 | 推定 \(T\) までの \(\int\|\omega\|_\infty dt\) が有限に収束するという、解像度安定な結果しか得られない |
| O-S | Serrin | いずれかの正則性クラス \(L_t^qL_x^p\) の有限性が厳密に示される |
| O-AS | 軸対称 | 旋回が恒等的にゼロ、または非零性が離散誤差以下 |
| O-AX | 特異位置 | 集中中心が物理時刻 \(T\) で軸へ到達しない |
| O-E | 有限エネルギー | 初期エネルギーが無限、または境界流出を除いてエネルギー不等式と不整合 |
| O-LEI | 局所エネルギー | suitable weak limit を作るのに必要な局所エネルギー制御を失う |
| O-V | 渦度可積分性 | 臨界渦度ノルムが有限という厳密上界が成立する |

「不合格でない」は特異点の証拠ではない。それは既知定理との即時矛盾がまだ見つかっていない、というだけである。
