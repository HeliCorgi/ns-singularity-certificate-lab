# 壁依存性実験の前登録(preregistration)

状態: **前登録済み・未実行**。登録日 2026-07-28(branch `fable5-mainline`)。
本書は実行前に閾値と判定規則を固定するための文書であり、実行後の変更は
旧版を保存した上で別系列として記録する(`docs/threat_model.md` §2.2)。

## 1. 問い

Hou の有限円柱成長機構(E-29 初期値、E-27 壁条件)は、壁 \(r=1\) に
本質的に依存するか。これは本リポジトリの Clay 目標(全空間・無外力)への
適用可能性を左右する分岐点である([Hou21] 自身は壁を容器と位置づけ、
特異点は軸上原点で主張するが、v1→v2 の解釈反転履歴
(`docs/hou_setup_audit.md` §9)を踏まえ、独立に測定する)。

## 2. 実験族

壁半径 \(R_{\mathrm{wall}}\in\{1,\ 1.5,\ 2,\ 3\}\) の入れ子円柱。
全ケースで共通:

- **初期値族(\(C^\infty\) envelope)**: E-29 の式を \(r>1\) へ形式的に
  延長してはならない(\((1-r^2)^{18}\) は \(r>1\) で増大する不正な式に
  なる)。またゼロ延長は \(C^{17}\) 止まりである。代わりに

  \[
  \tilde u_1(0,r,z)=u_1^{E29}(0,r,z)\,\chi_c(r^2),
  \qquad
  \chi_c(\rho)=
  \begin{cases}
  1 & \rho\le\rho_1=0.81\ (r\le0.9)\\
  \dfrac{\theta\!\big(\frac{\rho_2-\rho}{\rho_2-\rho_1}\big)}
        {\theta\!\big(\frac{\rho_2-\rho}{\rho_2-\rho_1}\big)
        +\theta\!\big(\frac{\rho-\rho_1}{\rho_2-\rho_1}\big)}
    & \rho_1<\rho<\rho_2\\
  0 & \rho\ge\rho_2=0.9025\ (r\ge0.95)
  \end{cases}
  \]

  \(\theta(s)=e^{-1/s}\ (s>0),\ 0\ (s\le0)\) の標準 \(C^\infty\) 遷移関数。
  \(\chi_c\) を \(\rho=r^2\) の関数として定義するため偶対称性・軸正則性は
  自動的に保たれる。性質:

  1. **core 同一性**: \(r\le0.9\) で E-29 と厳密に一致(\(\chi_c\equiv1\))。
     全壁半径で core 初期値は同一。
  2. **微小変形**: 変形は \(r\in(0.9,0.95)\) のみで、そこでの E-29 振幅は
     \(12000\cdot(1-0.81)^{18}\cdot\max|g|\approx3.4\times10^{-10}\)
     (場の最大 3266 に対し相対 \(\approx10^{-13}\))。導出ノルム E-29b
     (最大点 \(r=0\) と \(r=1/\sqrt{37}\approx0.164\))は不変。
  3. **compact support**: \(r\ge0.95\) で厳密に 0。全壁半径
     \(R_{\mathrm{wall}}\ge1\) に対し壁より手前で消える。
  4. \(C^\infty\)、軸互換(偶、\(r^2\) の関数)、有限エネルギー
     (有界 support+周期 z)。
  5. \(\omega_1(0)=0\)、\(\psi_1(0)=0\) は E-29 と同じ。

  この族と受入検査は実装時に equation_audit へ **E-32** として追記する。

- **初期値族の受入検査(事前指定)**:
  (i) \(r\le0.9\) で \(\tilde u_1=u_1^{E29}\) が bit 一致;
  (ii) \(\sup_r|\tilde u_1-u_1^{E29}|\le5\times10^{-10}\)(全域);
  (iii) \(r\ge0.95\) で厳密に 0;
  (iv) \(\max|\tilde u_1(0)|\) と Cartesian \(\|\omega(0)\|_\infty\) が
  E-29b と相対 \(10^{-12}\) で一致;
  (v) 遷移帯を跨ぐ高階差分の有界性(離散 \(C^4\) スポット検査);
  (vi) 軸 parity 検査合格。
- \(z\) 周期 1(固定。半径のみ拡大するため aspect 比が変わる点は
  §6 の限界に記載)。
- 粘性 \(\nu=5\times10^{-4}\)(第 1 段のみ、\(t\le T_1\))。
- 壁条件: E-27 を \(r=R_{\mathrm{wall}}\) に適用
  (\(\psi_1=0\)、\(u_1=0\)、Thom 型 E-31)。
- 目標時刻: \(T_1=0.002191729\)。
- CFL 0.1、`max_time_step` 1e-6(`hou_early_time` と同一)。

**core 解像度固定**: \(\Delta r=1/192\)、\(\Delta z=1/384\) を全ケースで
固定し、\(n_r=192R_{\mathrm{wall}}+1\)(193, 289, 385, 577)、
\(n_z=384\)。これにより core 領域 \(r\le0.9\) の離散化は全ケースで同一。

**解像度整合検査**: \(R_{\mathrm{wall}}=1,2\) の 2 ケースについては
\(\Delta r=1/128\)(粗)でも実行し、壁効果の測定値が離散化に対して
安定であることを確認する(不安定なら判定保留)。

## 3. 主要測定量(事前指定)

共通 core \(\Omega_c=\{r\le0.9\}\) 上で、各 snapshot 時刻
\(t\in\{0.0005, 0.001, 0.0015, T_1\}\) において:

1. 増幅率 \(A_R(t)=\|\omega\|_{L^\infty(\Omega_c)}(t)/\|\omega(0)\|_{L^\infty}\)
2. \(u_1\) の argmax 位置 \((R(t),Z(t))\)
3. \(\max_{\Omega_c}|\psi_{1,z}|\)(meridional 流の強さ)
4. core エネルギー(E-20 測度、\(\Omega_c\) 制限)
5. 楕円非局所寄与: 同一 \(\omega_1\)(core 制限)に対する
   \(\psi_1\) の差 \(\max_{\Omega_c}|\psi_1^{(R)}-\psi_1^{(R')}\)|
6. 尾部振幅 \(\max_{r>1.1}|u_1|,|\omega_1|\)(\(R_{\mathrm{wall}}>1\) のみ)

## 4. 事前固定する判定規則

隣接半径ペア \((R,R')=(1,1.5),(1.5,2),(2,3)\) について
\(S(R,R')=|A_R(T_1)-A_{R'}(T_1)|/A_{R'}(T_1)\) を定義する。

- **壁依存の判定**: \(S(2,3)>0.20\)、または \((R(T_1),Z(T_1))\) の位置差が
  \(>10\%\)(ノルム比)であり、かつ両測定が §2 の解像度整合検査を通る場合、
  この実装における Hou 機構は「**壁依存**」と分類し、Clay 候補と呼ばない
  (handoff §8.1)。
- **壁独立の示唆**: \(S\) が半径増加とともに単調減少し \(S(2,3)\le0.05\)
  の場合、「この有限族では壁効果は測定上小さい」と記録する。これは
  **全空間での壁独立の証明ではない**(有限格子 1 系列の数値観察)。
- 中間結果(\(0.05<S(2,3)\le0.20\) など)は「未決」とし、より大きい半径
  または高解像度を別実験として前登録する。
- いずれの場合も негative result を含め全結果を保存・報告する。

## 5. 実行計画と費用見積

`run_hou_early_time` を一般化した `run_wall_dependence` 実験
(壁半径・初期値延長・core 制限診断を追加)として実装する。

193×384 の約 3 倍のセル数、advective CFL は core 支配で同程度
→ 1 run あたり数時間以内(本セッションの 193×384 実測から外挿)。
全 6 run(主 4 + 粗 2)で半日程度。CPU のみ。

## 6. 既知の限界(事前明記)

- \(z\) 周期 1 固定のまま半径だけ拡大するため、領域の aspect 比が変わる。
  完全な「壁を無限遠へ」の極限ではない。
- 一様格子の core 解像度は Hou の適応格子に遠く及ばず、本実験が測るのは
  「この離散化・この時間区間における壁半径感度」である。
- \(T_1\) までの早期区間に限定する。後期(粘性切替後)の壁依存性は
  別実験。
- 外側境界 \(\psi_1(R_{\mathrm{wall}})=0\) は依然として人工的な有限領域
  条件であり、全空間 Green 関数処理(handoff §8.3)の代替ではない。
