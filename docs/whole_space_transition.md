# 全空間への移行: 楕円打切りの設計判断

状態: **設計文書**(2026-07-28)。E-33 の導出結果を受けて、FABLE5_HANDOFF
§8.3「全空間楕円処理」の選択肢を定量的に比較し、次の実装対象を決める。
数値実験の結果ではなく、監査済み式に基づく設計判断である。

## 0. 語彙の固定(P0-E、2026-07-28 改版)

本書の W-A 実測(§6)と壁依存性実験(`outputs/wall_dependence_v1`)の
結果は、いずれも

> **periodic-z radial-wall sensitivity observation**
> (周期 \(z\) における radial 壁感度の数値観察)

であり、それ以上ではない。周期 \(z\)(周期 \(L_z\))は非零 Fourier モードに
\(|k|\ge2\pi/L_z\) を強制するため、各モードの radial 楕円 tail は
\(K_1(kR)/I_1(kR)\) で急減し、壁を遠ざけた際の差の小ささは主として
この低波数 gap の帰結である。したがってこれらの結果を

- 「whole-space validation」
- 「\(\mathbb R^3\) wall independence」(全空間の壁独立性)

と表現してはならない。非周期 \(z\)・連続低波数スペクトル・free-space
Green tail に対する壁独立性は**未検証**である。真の全空間移行 gate は
§7 に定義し、それが通るまで現在の Hou 機構を Clay の \(\mathbb R^3\)
候補と呼ばない。過去の版でこの区別が曖昧な文があれば、本節が優先する。

## 1. 問題

有限円柱 \(0\le r\le R\)、周期 \(z\)、外側 Dirichlet \(\psi_1(R,z)=0\) で
\(-\mathcal L_5\psi_1=\omega_1\) を解く現行実装は、\(\mathbb R^3\) 問題の
近似としてどれだけの誤差を持つか。E-25 の監査警告どおり、これを
「全空間解」と同一視してはならない。

## 2. E-33 が与えた定量的答え

軸方向モード \(k\) ごとに、compact support の \(\omega_1\) に対して壁が
誘起する誤差は core 上で厳密に \(K_1(kR)/I_1(kR)\) に比例する(E-33c)。
したがって

| 領域 | 壁打切り誤差 | 必要半径 |
|---|---|---|
| \(kR\gg1\) | \(\sim\pi e^{-2kR}\)(指数) | \(R\sim\frac{1}{2k}\log\frac1\varepsilon\) |
| \(kR\ll1\) | \(\sim2/(kR)^2\)(代数 \(R^{-2}\)) | \(R\sim(k\sqrt\varepsilon)^{-1}\) |

**Hou 設定は指数域の奥にある**(\(L_z=1,R=1\Rightarrow kR=2\pi\approx6.28\))。
壁依存性実験で測った \(S=1.6\times10^{-4}\to2.9\times10^{-7}\to5.2\times10^{-10}\)
はこの指数減衰そのものである。

**しかし \(\mathbb R^3\) では \(k\to0\) まで連続に存在する**。長波長成分の
打切り誤差は \(R^{-2}\) でしか減らないので、\(\varepsilon=10^{-6}\) を
得るには core 半径の \(10^3\) 倍の壁半径が要る。一様格子では不可能、
写像格子でも core の \(O(10^{-8})\) と合わせて動的レンジ \(10^{11}\) を
要求する。**大半径 Dirichlet 円柱は全空間近似として代数的にしか
収束せず、実用的でない。**

## 3. より良い選択肢: 厳密なモード別透過条件(DtN)

E-33b の modal 構造は、外側境界に**厳密な**条件を課せることを意味する。
support の外で \(\hat\psi_k=A\,r^{-1}K_1(kr)\) なので、

\[
\frac{d}{dr}\!\left[\frac{K_1(kr)}{r}\right]
=-\frac{k K_0(kr)}{r}-\frac{2K_1(kr)}{r^2}
\quad\Longrightarrow\quad
\frac{\hat\psi_k'}{\hat\psi_k}=-\frac2r-k\frac{K_0(kr)}{K_1(kr)}.
\]

すなわち各モードで

\[
\boxed{\;
\partial_r\hat\psi_k(R)
+\Big[\frac2R+k\,\frac{K_0(kR)}{K_1(kR)}\Big]\hat\psi_k(R)=0
\;}
\tag{W-1}
\]

を課せば、\(\omega_1\) が \(r<R\) に compact support を持つ限り
**打切り誤差は厳密にゼロ**(離散化誤差を除く)。

極限の健全性:

- \(k\to0\): \(K_0/K_1\sim x(-\log(x/2)-\gamma)\to0\) なので (W-1) は
  \(\partial_r\hat\psi+2\hat\psi/R=0\)。これは \(k=0\) の減衰解
  \(\psi=C/r^2\) が満たす条件そのもの(残差を数値確認: 0)。
  E-33e の \(-Q_\infty/(2R^2)\) 誤差が**完全に消える**。
- \(kR\gg1\): \(K_0/K_1\to1\) なので係数は \(2/R+k\)、すなわち
  \(\partial_r\hat\psi\approx-k\hat\psi\) の外向き指数減衰。妥当。

**実装コスト**: solver A / B は \(z\) について Fourier で、モードごとに
radial 三重対角系を解いている。最終行の Dirichlet identity 行を (W-1) の
2 次離散化(片側差分または ghost cell)に差し替えるだけでよい。
係数 \(K_0(kR)/K_1(kR)\) は E-33 検証で作る Bessel oracle を再利用する。

**制約と未解決点**:

1. **compact support の仮定**。非線形発展では \(\omega_1\) の support は
   移流と拡散で広がる。(W-1) は \(\omega_1\) が \(r\ge R\) で厳密に 0 で
   ある場合にのみ厳密である。実運用では \(r\ge R\) の \(\omega_1\) の
   大きさを診断として監視し、閾値を超えたら停止または \(R\) を拡大する
   規則を前登録する必要がある。
2. **solver C との非互換**。(W-1) はモード対角なので Fourier 経路
   (A, B)には自然に入るが、実空間 \(z\) 差分の solver C では \(z\) について
   非局所になる。C は当面 Dirichlet のまま独立検証に用い、透過条件経路の
   独立検証には「大半径 Dirichlet 解との一致」を使う(下記 §4 の受入条件)。
3. **物理的な壁との区別**。(W-1) は**全空間問題の近似のため**の透過条件で
   あり、Hou の再現(E-27 の no-slip 物理壁)には使わない。両者を混同しては
   ならない。実験 config で明示的に選択させ、summary に記録する。
4. 離散化した (W-1) は厳密条件の 2 次近似なので、打切り誤差は消えても
   境界離散化誤差 \(O(\Delta r^2)\) は残る。

## 4. 実装計画(次の対象)

> **状態(2026-07-28 追記): W-A 実装完了、W-B の受入条件 6 件すべて合格。**
> 実装は `src/ns_certificate_lab/transparent_boundary.py`、証拠は
> `outputs/transparent_boundary_v1`(全 25 受入検査合格、3.5 秒)。
> 実測は §6 に記載。

**W-A. 透過境界条件付き楕円ソルバ.** solver A に (W-1) の 2 次離散化を
追加(既存 Dirichlet 経路は残し、config で選択)。

**W-B. 受入条件(実装前に固定).**

1. **厳密性テスト(\(k=0\))**: compact support source に対し、透過条件の
   解は core 上で \(R\) に依存しない。異なる \(R\) の解の差が
   \(O(\Delta r^2)\) の離散化誤差水準に留まり、Dirichlet の
   \(Q_\infty/2\,(R'^{-2}-R^{-2})\) が消えること。
2. **厳密性テスト(\(k>0\))**: 同様に \(R\) 非依存性を、複数の \(L_z\) で
   確認。特に \(kR\ll1\) の長波長域で Dirichlet 比の改善倍率を記録。
3. **収束**: manufactured 解で境界行込みの 2 次収束。
4. **大半径 Dirichlet との一致**: 十分大きい \(R_{\rm big}\) の Dirichlet 解
   と、小さい \(R\) の透過解が core 上で \(O(\Delta r^2)+O(R_{\rm big}^{-2})\)
   で一致すること(独立経路による検証)。
5. **故障注入**: (W-1) の符号反転、\(2/R\) 項の脱落、\(K_0/K_1\) を 1 に
   固定(\(kR\gg1\) 近似の誤用)を各々検出すること。
6. **support 漏れ検出**: \(r\ge R\) に有意な \(\omega_1\) を置いた入力を
   拒否または明示的に警告すること。

**W-C. 非線形への接続(後続)**。透過条件が楕円ゲートを通ったら、
`nonlinear_cylinder` の楕円 solve を切り替えられるようにし、
support 漏れ診断を毎 step 記録する。ただしこれは**全空間探索用**であり、
Hou 再現の run は物理壁のまま維持する。

## 6. W-A の実測結果(2026-07-28)

実装は `transparent_boundary.py` に置いた。solver A の import 集合は
テストで固定されており(`test_solver_does_not_import_existing_cylindrical_operator_or_pde_modules`)、
`bessel_reference` を足すとその assertion を弱めることになるため、
別 module から solver A の `_radial_flux_coefficients` と
`_solve_tridiagonal` を再利用する形にした。Dirichlet 分岐は
`solve_streamfunction_poisson` へそのまま委譲するので bit 一致は
構造的に保証され、テストでも固定している。

**離散化と次数(正直な記載).** \(\omega_1\equiv0\ (r\ge R)\) なので
連続解は \(R\) を越えて滑らかに接続し、ghost 節点 \(r_{N+1}=R+\Delta r\) は
架空点ではない。E-26 の**内部行をそのまま** \(i=N\) に書き、(W-1) の
中心差分形 \((\psi_{N+1}-\psi_{N-1})/(2\Delta r)+\beta_k\psi_N=0\) で
ghost を消去する。\(\beta_k\psi(R)=-\psi'(R)\) が厳密なので ghost 欠損は
\((\Delta r^3/3)\psi'''(R)\)、\(a_N^+=O(\Delta r^{-2})\) を掛けて
**この 1 行の局所打切りは \(O(\Delta r)\)**。全体が 2 次になるのは、
行列が既約優対角 M-matrix(\(\beta_k>0\) より第 \(N\) 行が狭義優対角)で
flux 形の \(1/V_i\) スケーリングを持つため \(A^{-1}\) の該当列が
\(O(\Delta r)\) だからである。これは仮定ではなく測定した(条件 3)。
\(k=0\) は明示分岐で \(\beta_0=2/R\) を bit 単位で使い、
\(K_0/K_1\) を引数 0 で呼ばない。FFT の負周波数が内向き増大条件に
ならないよう \(|k|\) を用いる。

**測定値**(\(a=0.95\)、\(p=8\)、core \(r\le0.9\)、\(1/\Delta r\in\{64,128,256\}\)):

| 条件 | 結果 |
|---|---|
| 1. \(k=0\) 厳密性 | core の \(R=1\!\to\!2\) 差は透過 \(9.07\text{e-}7\to2.27\text{e-}7\to5.66\text{e-}8\)(次数 2.0002)。Dirichlet は \(-1.6969516537\text{e-}3\) で**変化しない**。改善率 1872 → 7489 → **29959**。E-33e の offset は消え、2 次で 0 へ収束する量に置き換わった |
| 2. \(k>0\) 厳密性 | \(L_z=1\)(\(kR=6.28\))×11013、\(L_z=8\)(0.785)×31787、\(L_z=32\)(0.196、代数域)×30510、最大 ×34231。全 24 の観測次数は [1.948, 2.001] |
| 3. manufactured 収束 | 外側が厳密 \(K_1(kr)/r\)、内側は 4 階まで一致する偶 6 次で接続(compact source が厳密ゼロ)。全行 1.9975–2.0038、**境界行のみ 2.0099–2.0150** |
| 4. 大半径 Dirichlet 一致 | \(k=0\): 総差 8.899e-6 = 壁項 8.838e-6(閉形式、oracle 上界 8.839e-6)+ 残差 **6.08e-8**(\(/\Delta r^2\) は全格子で 3.99e-3、次数 2.0002) |
| 5. 故障注入 | 符号反転 3628–4152 倍、\(2/R\) 脱落は \(k=0\) 行が特異になり**ソルバが拒否**(\(k>0\) 単一モードでは 130–56164 倍)、\(K_0/K_1\!:=\!1\) は 22.5–186 倍 |
| 6. support 漏れ | 宣言 support \(\ge R\)、および宣言 0.95 で実体が 1.05 まで伸びる場合(残渣 9.21e-7)を共に拒否 |

**正直に記録した限界.**

- `frozen_ratio` 故障は \(k=0\) で**bit 単位で不可視**(どちらでも
  \(\beta=2/R\))。実験は bracket が不変な case を検出要求から除外し
  名前を出す(`cases_whose_bracket_is_bitwise_unchanged`)。
- 条件 4 の \(L_z=32\) では、比較対象の \(R_{\rm big}=16\) Dirichlet 解
  自体が収束していない(総差 3.891e-7 に対し壁項上界 3.309e-7)。
  これは E-33 の代数 \(R^{-2}\) そのものであり、`known_gaps` に記録した。
- \(K_\nu\) の求積は大引数で劣化する(\(x=3000\) で step-halving 欠損
  2e-3)。E-33 の範囲(\(x\le60\))では届かないが、細かい透過格子の
  Nyquist モードでは届く。\(x>10^3\) で文書化した漸近形へ切り替え、
  切替点で両分枝が \(10^{-8}\) 未満で一致することを確認、切替モード数を
  metadata に記録する。

**Hou 再現との分離.** config は E-27 を名指しする
`physical_wall_warning` を必須とし、solver metadata と summary にも
`outer_boundary_scope_warning` / `outer_boundary_condition` を記録する。
既定は全経路で Dirichlet のままなので、Hou 経路が暗黙にこれを拾うことは
ない。

## 7. 真の全空間移行 gate(P0-E、実装前定義、未実行)

W-A(透過 radial 境界)は全空間移行の**radial 成分のみ**を解決する。
Clay の \(\mathbb R^3\) 問題へ向けた gate は以下をすべて要する。
本節は仕様であり、いずれも**未実装・未実行**である。

1. **非周期 \(z\) の有限 box**: 周期 \(z\) を外し、\(z\) 方向にも打切り
   境界を持つ領域で解く。周期像(periodic image)効果と radial 壁効果を
   分離して測る。
2. **初期値の \(z\) 方向 \(C^\infty\) compact 台**: E-32 の radial envelope
   に加え、\(z\) にも滑らかな compact 台を持つ初期値族。radial 依存は軸
   正則性のため \(r^2\) の滑らかな関数として設計する(E-32 と同じ制約)。
3. **free-space 楕円解**: \(-\mathcal L_5\psi_1=\omega_1\) を全空間条件で
   解く経路を少なくとも一つ: (a) 5 次元 Poisson 対応の Green 積分、
   (b) Hankel(\(r\))×Fourier/連続変換(\(z\))、(c) 多重極/人工境界条件
   (W-1 の \(z\) 非周期版)。
4. **独立な \(R_{\max}\)・\(Z_{\max}\) 拡大**: 両方向の打切りを独立に
   動かし、感度を別々に記録する。domain doubling だけでなく、解析的
   tail 上界または独立 Green solver で外側誤差を評価する。
5. **低波数 stress test**: \(L_z\in\{1,2,4,\dots\}\) 系列で
   指数域→代数域への遷移を実測し、機構が低波数の連続極限で
   生き残るかを判定する(stop condition: 「\(z\) period を増やすと機構が
   大きく変わる」)。
6. **\(\mathbb R^3\) 有限エネルギーの直接検査**: Cartesian 体積測度での
   エネルギー・enstrophy を直接計算する(円柱測度からの換算でなく)。
7. **同一視の禁止**: 全空間候補を有限円柱 no-slip 解と同一視しない。
   両者は別の境界値問題であり、一致は測定対象であって仮定ではない。

## 5. この文書が主張しないこと

- 透過条件を入れても、軸近傍の未解像(相対軸パリティ 0.706 at 65×128)は
  解消しない。楕円打切りと格子解像度は独立の問題である。
- 全空間楕円処理が正しくなっても、それは候補探索の前提が一つ整うだけで
  あり、特異点の存在にも Clay 問題にも近づかない。
- (W-1) は \(\omega_1\) の compact support を仮定する。真に無限遠まで
  裾を持つ解では、裾の寄与を別途評価しなければならない
  (handoff §8.3 の Green tail は完全には消えない)。

## Gate 4 の実装と合格記録(2026-07-29 第 4 便)

本書 §7 が要求する**線形**ゲートは
[whole_space_gate.py](../src/ns_certificate_lab/whole_space_gate.py) として
実装され、`outputs/whole_space_gate4_v1` で前登録受入検査 20 件すべてに
合格した。要点のみ記す(数値は `STATUS.md` の当該節)。

- **参照解が厳密**: `L₅` は 5 次元 Laplacian の軸対称版なので、5 次元半径
  `R=√(r²+z²)` のコンパクト台 bump に対し Newton の公式が閉形式で解ける。
  `z` 平行移動不変性から、異なる `z₀` に置いた bump の重ね合わせも厳密。
  求積も離散化も含まないので、参照解は独立である。
- **軸方向経路が非 FFT**: `z` は非周期 Dirichlet なので、内部の 2 階差分は
  `numpy.sin` から組んだ密な DST-I 行列で厳密に対角化される。既存ソルバが
  共有する `numpy.fft` の規約とは何も共有しない。本書と
  `docs/formalization_map.md` が挙げていた「非 Fourier の独立 z 方向経路」は
  これで埋まった。
- **ゼロ軸モードが存在しない**: 非周期 Dirichlet の固有値は
  `λ_m = −4sin²(mπ/2(N+1))/Δz²` で常に狭義負。周期 `z` の `k=0` モードが
  持つ `R⁻²` 半径尾部(`docs/low_frequency_wall_obstruction.md`)は
  **周期性の産物**であり、自由空間では 5 次元単極子の `R⁻³` に置き換わる。
  両者の比は厳密に `2R/L` で、**周期箱を大きくするほど誤差が線形に悪化する**。
  これが「周期箱を拡大して全空間に近づける」設計が成立しない理由である。
- **打切り誤差の分離**: 内部誤差は離散化誤差に支配されるため、領域拡大の
  効果は**同一格子間隔での共通内部差分**で分離した。零トレースで `D⁻³`、
  単極子トレースで `D⁻⁴`(実測 3.11/3.13 と 3.85/3.74)。
- **a posteriori 上界**: `|ψ_∞ − M₅G| ≤ 3a‖ω‖_{L¹(dV₅)}/(8π²(|X|−a)⁴)`。
  5 次元 Laplacian の最大値原理により、これは連続レベルの領域打切り誤差を
  box 内部の全点で抑える。**離散化誤差は抑えない**(半径行 `i=1` は
  M-matrix ではなく離散最大値原理がない)。
- **周期像誤差と壁誤差の分離は連続レベルで行った**。理由を隠さずに書けば、
  本リポジトリが払える刻み幅では 4 経路すべての実測誤差が離散化誤差に
  支配され、周期像の寄与(`~10⁻⁶`)を実測で分離できなかったからである。

**このゲートが許可すること**: 非線形時間発展への結合(API は
`WholeSpaceEllipticSolver.coupling_contract()`)。
**許可しないこと**: 得られる発展についてのいかなる主張も。
