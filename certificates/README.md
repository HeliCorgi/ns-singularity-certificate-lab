# Candidate certificates

This directory is reserved for explicit candidate arrays or spectral
coefficients plus a manifest containing schema version, configuration, seed,
coordinates, units, normalization, physical time, viscosity, basis convention,
source/runtime provenance, array metadata, and cryptographic hashes.

No candidate is included in the initial foundation milestone.  A valid file in
this directory is evidence for a reproducible numerical object only; it is not
a proof of singularity.
